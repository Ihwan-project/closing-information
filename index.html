3 · Daftar penerima Telegram

Token bot dan daftar penerima tersimpan permanen di browser ini, jadi cukup diisi sekali.
Cara menyiapkan (sekali saja):
1. Buka Telegram → chat @BotFather → kirim /newbot → salin token yang diberikan ke kolom di bawah.
2. Minta setiap pegawai penerima membuka bot tersebut dan menekan Start (atau kirim satu pesan apa saja). Untuk grup: masukkan bot ke grup, lalu kirim satu pesan di grup.
3. Tekan tombol Deteksi penerima baru — Chat ID akan terisi sendiri. Tidak perlu tahu nomor HP.
